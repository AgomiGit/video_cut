給剛接觸程式與剪片的人看的專案文件

用程式自動找出影片精華

這個工具會先把影片變成文字和時間點，再找出「可能很有趣、很重要、很適合剪出來」的片段，最後用 ffmpeg 合成一支精華影片。

▶ 開始看怎麼用 ⌘ 看流程圖
本機優先

主要工作在你的電腦上完成，不需要把整支影片丟給雲端 AI。

可以分段重跑

準備、打分、排片、輸出可以分開做，失敗時不用全部重來。

先用規則省力

先用關鍵字和說話密度縮小範圍，AI 只看比較有機會的片段。

如何使用此工具剪片

你可以把它想成一位剪片助理：你給它原始影片，它先聽聲音、讀字幕、找亮點，再把精華片段接成新影片。

1

把影片放到專案資料夾

例如把手機影片放在專案根目錄，檔名可以是 input.mp4 或 IMG_4935.MOV。

ls
2

一行指令跑完整流程

最簡單的方式是用 run。下面例子會做出大約 180 秒的精華影片，用 qwen2.5vl:7b 看縮圖，並用 qwen3:1.7b 幫文字片段打分。

$ uv run python auto_highlight.py run input.mp4 --out work/video1 --target-duration 180 --visuals --vision-model qwen2.5vl:7b --planner ollama --model qwen3:1.7b
→ 讀影片
→ 找片段
→ 輸出 highlight.mp4 
uv run python auto_highlight.py run input.mp4 --out work/video1 --target-duration 180 --visuals --vision-model qwen2.5vl:7b --planner ollama --model qwen3:1.7b
3

想慢慢檢查，就分段執行

如果影片很長，建議分段執行。每一步會留下檔案，方便你知道程式做到哪裡。

prepare1
score2
plan3
render4
uv run python auto_highlight.py prepare input.mp4 --out work/video1
uv run python auto_highlight.py analyze-visuals work/video1 --vision-model qwen2.5vl:7b
uv run python auto_highlight.py score work/video1 --planner ollama --model qwen3:1.7b
uv run python auto_highlight.py plan work/video1 --target-duration 180
uv run python auto_highlight.py review-gate work/video1
uv run python auto_highlight.py apply-review work/video1
uv run python auto_highlight.py render work/video1
4

打開輸出的精華影片

完成後，影片會在 work/video1/output/highlight.mp4。如果不滿意，可以調整秒數或重新跑分。

open work/video1/output/highlight.mp4
小提醒： 如果 work/video1 已經有舊成果，請換一個新資料夾，例如 work/my_first_cut，這樣比較不會蓋到之前剪好的內容。

事前需要安裝哪些工具

這個專案像一個小隊伍。Python 負責指揮，ffmpeg 負責處理影片，faster-whisper 負責把聲音變文字，Ollama 是可選的本機 AI 評審。

Py
uv 與 Python

用來執行 auto_highlight.py，也幫忙管理 Python 套件。

FF
ffmpeg / ffprobe

把影片轉音訊、切片段、接影片、輸出 MP4。

Wh
faster-whisper

聽影片聲音，產生有時間點的逐字稿。

AI
Ollama，可選

如果你想用本機模型幫文字打分或描述縮圖，可以安裝它。

macOS 安裝方式

如果你有 Homebrew，安裝會比較簡單。

brew install ffmpeg uv
uv sync --extra transcribe

Ollama 可到官方網站下載，或用 Homebrew 安裝。qwen3:1.7b 用來看文字片段，qwen2.5vl:7b 用來描述縮圖。

brew install ollama
ollama pull qwen3:1.7b
ollama pull qwen2.5vl:7b

Windows 安裝方式

建議先裝 Python，再用 PowerShell 安裝 uv。ffmpeg 可用 winget 安裝。

winget install Gyan.FFmpeg
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv sync --extra transcribe

Ollama 可以從官方網站下載 Windows 版，裝好後再拉模型。qwen3:1.7b 看文字，qwen2.5vl:7b 看縮圖。

ollama pull qwen3:1.7b
ollama pull qwen2.5vl:7b

Linux 安裝方式

下面以 Ubuntu / Debian 類系統為例。

sudo apt update
sudo apt install ffmpeg python3 python3-pip
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync --extra transcribe

Ollama 是可選項，需要本機模型時再裝。文字打分用 qwen3:1.7b，縮圖描述用 qwen2.5vl:7b。

curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen3:1.7b
ollama pull qwen2.5vl:7b
檢查項目 指令 看到什麼代表成功
ffmpeg ffmpeg -version 出現版本號，不是 command not found。
uv uv --version 出現 uv 的版本號。
Ollama，可選 ollama list 能列出模型，或至少沒有找不到指令。

此專案的演算法

演算法就是「做決定的方法」。這個工具不會直接叫 AI 看完整支影片，因為那樣很慢也很花錢。它會先用便宜的方法縮小範圍，再挑出最值得剪的地方。

1. 讀影片

用 ffprobe 確認影片長度，用 ffmpeg 抽出聲音。

2. 聲音變文字

faster-whisper 產生逐字稿，每句話都有開始和結束時間。

3. 找候選片段

看到「哇、你看、好吃、景點」等字，就把前後幾秒抓出來。

4. 建立分析版影片

如果要看縮圖，會先產生 output 等級的 analysis_video.mp4，再從這個較小的 proxy 抽畫面。

5. 幫片段打分

看關鍵字、說話密度、情緒字、地點字，也可用 qwen3:1.7b 等本機模型補充判斷。

6. 排成剪輯計畫

挑高分片段，避免重複，盡量接近目標秒數。

7. 信心檢查

用 green/yellow/red 判斷剪輯計畫是否穩；yellow 或 red 時由 Codex CLI 接手審稿，再用 apply-review 驗證套用。

8. 輸出影片

ffmpeg 依照 edit_plan.json 切片、淡入淡出、合成 highlight.mp4。

候選片段是什麼？

候選片段就是「可能值得剪出來」的一小段影片。程式不會一開始就決定它一定好，只是先把它放進待選名單。

為什麼要合併？

如果兩個候選片段距離很近，例如只差 5 秒，通常是同一件事，所以合在一起比較自然。

分數怎麼想？

像老師改考卷一樣，不只看一題。它會看好笑、互動、地點、清楚度、可不可以單獨看懂。

Codex 什麼時候接手？

如果信心檢查是 green 就直接輸出；如果是 yellow 或 red，Codex CLI 會讀剪輯計畫、分數、review report 和縮圖，幫忙確認或重排片段。

簡化想法：總分 = 關鍵字 + 說話密度 + 互動感 + 情緒 + 地點價值 - 品質扣分

剪完後會看到哪些檔案

每次執行都會放在一個 work/<名字>/ 資料夾。這些檔案像剪片過程的作業本，可以幫你檢查哪一步出了問題。

檔案或資料夾 用途 用白話說
transcript.json 逐字稿和時間點 影片裡每句話大概在第幾秒說。
candidates.json 候選片段 程式覺得「可能有料」的片段清單。
scored_segments.json 片段分數 每段為什麼被看好，分數是多少。
edit_plan.json 最後剪輯計畫 真正要剪哪幾段、順序怎麼排。
output/highlight.mp4 完成影片 你最後要看的精華影片。

本頁是此專案的入門說明文件。設計目標是讓第一次接觸自動剪片的人，也能知道要安裝什麼、怎麼執行、程式大概怎麼做決定。
